# Integrações Externas Adiadas

Em 25/08/2026, o responsável pelo Netvius decidiu adiar os alertas externos. O sistema interno permanece publicado e não realiza qualquer envio automático por e-mail ou WhatsApp até nova autorização.

| Integração | Uso previsto | Condição para retomada |
|---|---|---|
| E-mail diário | Enviar o relatório operacional às 08:00 para os destinatários definidos pelo responsável | Escolha entre Resend com remetente verificado ou Gmail conectado, seguida de credenciais autorizadas |
| WhatsApp de novo cadastro | Avisar o número comercial informado quando uma nova conta for criada | Escolha entre Meta WhatsApp Business Cloud API ou Twilio WhatsApp, número habilitado e modelo de mensagem autorizado |

Nenhuma credencial, token, senha ou remetente foi armazenado neste documento. Ao retomar, a integração deverá ser configurada por segredo de ambiente e validada em ambiente controlado antes da publicação.
